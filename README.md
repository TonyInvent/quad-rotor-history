# Quad-Rotor / Multi-Rotor Flying Machine History

A comprehensive document tracing the development of multi-rotor flying machines from 1907 to the present, covering:

- **Early pioneers** — Breguet-Richet, Œhmichen, de Bothezat, Convertawings
- **Why gas engines failed** — throttle lag and the 40-year dormancy of quadrotors
- **Toy era** — Keyence Gyrosaucer (mechanical gyro), Draganflyer (piezo gyro)
- **Microdrone** — the first commercial quadcopter UAV (Germany, 2005)
- **Motor & ESC evolution** — brushed → BLDC square-wave → sine-wave → FOC
- **Rotor/propeller development** — wood to carbon fiber, low-Re aerodynamics
- **MEMS IMU revolution** — from Sperry gyroscopes to the MPU6050
- **Open-source flight controllers** — MultiWii → ArduPilot → PX4/Pixhawk
- **Control algorithm evolution** — PID → backstepping → sliding mode → geometric control on SO(3)
- **DJI & Shuo Yang's 2015 ICRA paper** — Lie algebra-based full-attitude quadrotor control
